# Everpure Resilience service - Tools
Tools installer for in-guest network and configuration management

## Overview
This tool installs in the guest and is called on a recovery when network configuration changes are configured.

## Usage
Included in the download is a Powershell script for Windows and a Shell script for Linux/Unix, which need to be ran with administrator or root priviledges.  It installs a script that is called by VMware Tools upon a recovery where a network configuration change is configured.  Can be deployed with tools including Microsoft MCM/SCCM.
